# VideoCutter

Лёгкий нативный редактор для macOS, ориентированный на быструю нарезку видео.

## Первый этап

- каркас SwiftUI-приложения;
- выбор MP4/MOV через кнопку или `Cmd+O`;
- предварительный просмотр через AVFoundation;
- заготовка видео- и аудиодорожки.

## Запуск

Требуется macOS 14+ и Xcode Command Line Tools:

```bash
./script/build_and_run.sh
```

Следующие этапы: интерактивный таймлайн, нарезка фрагментов, субтитры и экспорт.
