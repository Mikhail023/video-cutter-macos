# VideoCutter

Лёгкий нативный редактор для macOS, ориентированный на быструю нарезку видео.

## Возможности

- импорт видео MP4/MOV;
- собственные кнопки воспроизведения и перемотки без панели плеера Apple;
- раскадровка из миниатюр реальных кадров с playhead и выбором фрагментов;
- разрезание и удаление клипов, отмена и повтор действий;
- настройка скорости предпросмотра и громкости;
- маркеры важных моментов на таймлайне;
- экспорт собранного монтажа в MP4.

## Запуск

Требуется macOS 14+ и Xcode Command Line Tools:

```bash
./script/build_and_run.sh
```
